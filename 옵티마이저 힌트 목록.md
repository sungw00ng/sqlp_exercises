| 카테고리         | 힌트               | 짧은 설명                   |
| ------------ | ---------------- | ----------------------- |
| **최적화 목표**   | ALL_ROWS         | 전체 처리량 최적화, 배치 처리용      |
|              | FIRST_ROWS(N)    | 처음 N행 빠르게 반환, OLTP용     |
| **액세스 방식**   | FULL             | 테이블 전체 스캔               |
|              | INDEX            | 특정 인덱스 사용 강제            |
|              | INDEX_DESC       | 인덱스를 내림차순으로 사용          |
|              | INDEX_FFS        | 인덱스 패스트-풀 스캔            |
|              | INDEX_SS         | 단일 블록 인덱스 스캔            |
| **조인 순서**    | ORDERED          | FROM 절 순서대로 조인          |
|              | LEADING          | 특정 테이블을 조인 선두로 지정       |
|              | SWAP_JOIN_INPUTS | 조인 입력 순서 교환 허용          |
| **조인 방식**    | USE_NL           | Nested Loop 조인 강제       |
|              | USE_MERGE        | Merge Join 강제           |
|              | USE_HASH         | Hash Join 강제            |
|              | NL_SJ            | Nested Loop Semi Join   |
|              | MERGE_SJ         | Merge Semi Join         |
|              | HASH_SJ          | Hash Semi Join          |
| **서브쿼리 팩토링** | MATERIALIZE      | 서브쿼리를 임시 테이블로 처리        |
|              | INLINE           | 서브쿼리를 인라인 처리            |
| **쿼리 변환**    | MERGE            | 뷰 병합 허용                 |
|              | NO_MERGE         | 뷰 병합 금지                 |
|              | UNNEST           | 서브쿼리 언네스트 허용            |
|              | NO_UNNEST        | 서브쿼리 언네스트 금지            |
|              | PUSH_PRED        | 조건(predicate) 푸시 허용     |
|              | NO_PUSH_PRED     | 조건(predicate) 푸시 금지     |
|              | USE_CONCAT       | UNION ALL 처리 최적화        |
|              | NO_EXPAND        | Materialized view 확장 금지 |
| **병렬 처리**    | PARALLEL         | 테이블 병렬 처리 허용            |
|              | PARALLEL_INDEX   | 인덱스 병렬 처리 허용            |
|              | PQ_DISTRIBUTE    | 병렬 쿼리 분배 제어             |
| **기타**       | APPEND           | Direct-path insert 사용   |
|              | DRIVING_SITE     | 분산 쿼리에서 실행 위치 지정        |
|              | PUSH_SUBQ        | 서브쿼리 조건 푸시 허용           |
|              | NO_PUSH_SUBQ     | 서브쿼리 조건 푸시 금지           |
